# 2. What is a Span?

A Span is the most important concept in OpenTelemetry.

Think of a span as a stopwatch.

Example:
    GET /
    
    Start
     │
     │ 20 ms
     │
    Database
    
     │ 10 ms
     │
    Business Logic
    
     │ 5 ms
     │
    Return Response
    
    Stop
Everything between Start and Stop is one span.

Suppose your endpoint calls another service.
    GET /orders
    │
    ├── Database
    │
    ├── Redis
    │
    └── Payment API

Each one becomes another span.
    GET /orders
    │
    ├── SQL Query
    │
    ├── Redis
    │
    └── HTTP Call

Together these spans form a Trace.

# 3. What is a Trace?

A trace is simply

A collection of related spans.

Example: Trace

    GET /orders
    
    ├── SQL Query
    
    ├── Redis
    
    └── HTTP Payment

One request = one trace.

# Package	                                Purpose

opentelemetry-sdk	                    Records spans and manages exporting.
opentelemetry-instrumentation-fastapi	Automatically creates spans for incoming requests.
azure-monitor-opentelemetry-exporter	Sends spans to Azure Monitor.

Notice there is no magic package. Everything has one job.

# 4.2 Step 2 — Create the Tracer Provider

This is the heart of OpenTelemetry.

# Create a new file:

app/telemetry.py

For now, add only this:

from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider

provider = TracerProvider()

trace.set_tracer_provider(provider)

That's all.

# What does this do?

Imagine a hospital. Patients arrive.

Someone has to register every patient. The TracerProvider is the registration desk.
    Request
    ↓
    TracerProvider
    ↓
    Create Span

Without it, there is nowhere to store spans.
